# MicroGlideBoard — MVP

An experimental prototype of a new screen keyboard concept focused on reducing thumb movement during typing.

## Project Overview

MicroGlideBoard explores an alternative to conventional mobile keyboard layouts. Instead of tapping individual letter keys, users select groups of letters with one thumb and choose letters using directional gestures with the other.

The codebase consists primarily of four Kotlin files. It was largely generated by AI to rapidly test an unconventional input ergonomics hypothesis.

## Current Status

- Created for personal testing and experimentation, and for anyone interested in alternative keyboard designs.
- Development is currently frozen.
- The code is experimental, and the Gradle setup is minimal, but the MVP is functional.
- The input method and gesture recognition may have limitations and are not intended to be a polished daily-driver keyboard.
- Currently available only for Ukrainian, English and russian languages.

## Installation

1. Install the application on your Android device.
2. Open your system's keyboard settings and enable "MicroGlideBoard" under the available input methods.
3. Select "MicroGlideBoard" as your active keyboard.

The exact names of these settings may vary between Android devices.

## How to Use

MicroGlideBoard uses two-thumb input:

- Left thumb — letter groups: Touch the left area to activate a group. Move vertically to select a different group.
- Right thumb — letter selection: While the left thumb is active, move the right thumb in one of eight directions to enter the corresponding letter.
- Release to insert a space: Releasing the right thumb inserts a space, allowing words to be separated naturally.
- Repeat the last letter: Move the left thumb to the right of the active group.
- Delete: Move the left thumb to the left of the active group. Holding the gesture activates repeated deletion.
- Symbols: Select the symbol keyboard through its assigned directional gesture. The symbol layout includes multiple pages and long-press alternatives where supported.
- Language switching: Use the language-switch gesture to cycle through the available layouts.

The keyboard is designed around relative movement rather than individual letter keys. Experimentation and practice are expected.

## Features

- Two-thumb, gesture-based letter input.
- Directional selection across multiple letter groups.
- Support for Ukrainian, English, and Russian layouts.
- Repeated-letter input and deletion gestures.
- A dedicated symbol keyboard with additional symbols.
- Visual letter previews and directional hints.
- Custom-drawn interface implemented directly in Kotlin.
